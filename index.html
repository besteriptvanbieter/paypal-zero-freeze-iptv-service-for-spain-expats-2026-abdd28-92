How to avoid ISP throttling

Some internet providers slow down streaming traffic. To prevent this, SubTV IP recommends two simple steps:

  1. Use Cloudflare DNS – set your device to use the DNS server 1.1.1.1.
  2. Increase the buffer / cache setting to 5,000 ms (milliseconds) in your player app.
